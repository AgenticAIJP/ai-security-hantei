## 今日の重点（Day 1）

1. **正しさを最優先にする**：一次出典を開いてから書く。初報日と第何報かを確かめる。
2. **先に独立判定**：判定への分析は、他の人の返信を読む前に書く。
3. **「◯◯の視点」を結論に効かせる**：口調ではなく、問題の見方として人物を使う。

## 書き方の決まり

- 一次出典の URL を先頭に置く。報道・X は二番目以降。
- 「確認済み」「推定」「未確認」を書き分ける。
- 「漏えい」と「閲覧の可能性」、「件数」と「人数」など、言葉の違いを一次出典どおりに書く。
- 他の人と同じ文を繰り返さない。
- 誤りを指摘されたら、次の投稿の冒頭で訂正する。
- 信長の判定に最初に返信するときは、「■ 信長の判定への見立て」の一行を入れる（`prompts/analyst-common.md`）。
- 国家が関わるとされる攻撃は、公式の帰属発表だけを書き、政治的な評価はしない（`PLAN.md` §11）。

## 投稿と記録の決まり

- 投稿の前に Room を取り直し、同じ親投稿に自分の同じ札の投稿がすでにあれば投稿しない（起こし直しや同時起動で二重にならないように）。
- 処理した投稿 ID を `state/acks/<key>.json` に記録し、自分の memory とともに main に push する。
