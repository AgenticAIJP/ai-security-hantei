# 【最新版】の形

```
【最新版】<会社名・サービス名>：<何が起きたか、一行>（<発表の版と日時> 時点）

■ ひとことで：<読む人がまず知るべきこと、2 行まで>

■ 自分が対象か：
  <見分け方>
  抜けやすい人：<自分で入力していない人／見られた側／提携先・委託先の向こうの利用者／退会・解約した人。入るかどうかを一つずつ。入らないなら「入らない」>
  連絡が来ていないことは、対象外の印ではありません（発表が対象外と言い切っている場合を除く）。

■ 今夜やること（順番に 3 点まで）：
  1. <内容>（条件：<どの端末から、いつ>）
  2. …
  3. …

■ 来そうな詐欺と見分け方：
  <型>
  見分け方：自分で開いた公式の入口か、発表の窓口に、自分からかける。会社が「尋ねない」と書く物（<発表の言葉>）を求めたら偽物。

■ 端末の確認：<要／不要と理由>

■ 家族に伝えること：<1〜2 行>

■ 問い合わせ先：<公式の発表に載っている窓口（番号、受付時間、期限）>／公的な相談窓口：消費者ホットライン 188、警察相談専用電話 #9110（受付の曜日や時間は、それぞれの公式ページで確かめる）

■ 原因：<会社が認めた／報道・専門家／推定／未確認に分けて。未公表なら「未公表」>

■ 企業が持ち帰ること：
  1. そもそも持っている必要があったか：<…>
  2. <原因に結びつく改善。原因が未公表なら、原因が何であっても効く備え>
  3. <…>

■ 中小企業と開発者へ：<専任のいない会社や開発者が、今週確かめる一点>

■ AI の時代に変わること（推定）：<この弱点は AI でどう見つけやすくなるか。守る側は、先に見つける・早く気づく・早く直す・人が決める。AI で調べるのは自社と許可を得た範囲だけ>

■ もとにした発表：<一次出典の URL と版の日時>

■ このまとめについて：AI が書き、AI が点検しました。<点検で直した点を 1 行>。<確かめられなかった点>。発表は続報で変わることがあります。最後は公式の窓口で確かめてください。
```
