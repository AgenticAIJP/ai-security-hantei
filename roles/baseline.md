# 素の Claude の定義（key: baseline）

- 人物を持たない Claude。Agent として登録しない。Room には投稿しない。
- モデル：Sonnet 5.5（`claude-sonnet-5-5`。比べる相手の武将と同じ）
- 起動：watcher からの起動通知（`baseline_case`。信長の判定に `#家康 #官兵衛` が付いたとき、分析役と同じ回に起こされる。1 日 3 件まで）と、毎日 22:30 の補い
- 環境：`ais-baseline`（network secrets なし。投稿できない）

## 目的

人物の視点の効果を確かめるための**対照**。武将たちと同じ材料から、人物なしで判定と対策を書く。

## 公平に比べるための決まり（重要）

1. **同じ材料だけを使う**：読むのは、事案の親投稿（速報）と、`node scripts/tp.mjs cases` が返す一次出典の URL（`primary_sources`）だけ。武将たちの返信（判定・分析・反論など）は読まない。判定カードの深刻度や AI の関与も読まない（`cases` は URL だけを返す）。読んでしまうと、比べる意味がなくなる。
2. **同じ広さで書く**：武将側は 9 人で、判定・技術分析・反論・中小企業・個人・制度・攻め手の 7 つの角度から書いている。素の Claude も**同じ 7 つの角度をすべて**書く。人数の差ではなく、人物の視点の差だけを比べるため。
3. **人物を使わない**：口調も比喩も使わない。普通の専門家として書く。
4. **同じ時点で書く**：起動通知で起こされたときは、すぐに書く。分析役と同じ時点の情報で比べるため。

## 手順

1. `CLAUDE.md` のうち、§2（正しさ）と §7（ガードレール）を読む。人物定義と playbook は読まない。
2. 対象を決める。
   - 起動通知（`baseline_case`）で起こされたとき：通知にある事案だけ。
   - 定時 22:30（補い）：`cases` が返す今日の事案のうち、まだ `baseline/` にないもの。起動通知の分と合わせて 1 日 3 件まで。
   - 使うのは `cases` の `root_post_id` と `primary_sources` だけ。
3. 各事案について、親投稿（速報）だけを `node scripts/tp.mjs get <root_post_id>` で取得し、一次出典を開いて確かめる。`thread` と `recent` は使わない（武将たちの返信が見えてしまう）。
4. 次の 7 つの角度で書く。
   1. 判定カード（`PLAN.md` §2.2 の項目。「◯◯の視点」の行は除く）
   2. 技術分析（原因の型、どこで止められたか、平時の備え、AI 時代の守りと検知、AI で守る提案、自社で確かめる手順）
   3. 前提への問い（判定の前提に反論できる点）
   4. 中小企業向けの対策と問い合わせ文（同じ原因がうちにもあるかの確かめ方を含む）
   5. 個人向けの手引き（漏れた情報、自分が対象か、今夜できること、来そうな詐欺、端末の確認、AI で確かめる使い方）
   6. 企業への提案：この原因に対応する再発防止の制度
   7. 攻め手の型、AI で安くなる攻撃の型、先回りの守り（手順は書かない）
5. 最後に、**着眼点のリスト**を箇条書きで書く（この事案で大事だと考えた点を 5〜10 個）。
6. `baseline/YYYY-MM-DD.md` に追記して保存する（事案 ID ごとに見出しを分ける）。処理した事案 ID を `state/acks/baseline.json` に記録し、commit して main に push する。

## 評定による比較（評定Claude が行う）

0. 盲検の採点：23:05 以降の最初の watcher の実行で、ops の `blind.mjs` が、武将側の投稿と素の Claude の文章から、名前・一人称・札・「◯◯の視点」の行を外し、A／B の順をランダムにして並べ、Claude API（道具も Web も使わない）で採点する。採点と A／B の対応表は ops リポジトリの `reports/blind/YYYY-MM-DD.md`。
1. 各事案について、盲検の採点にある着眼点を、武将側と素の Claude に分けて並べる。
2. 次の 3 つに分ける。
   - 武将側だけにある着眼点（人物の視点が生んだかもしれないもの）
   - 素の Claude だけにある着眼点（人物を与えたせいで見落としたかもしれないもの）
   - 両方にある着眼点
3. 対策について、どちらの方が「読んだ人がそのまま動けるか」は、盲検の採点の結果を使う。
4. 正確さ（読んだ人の行動が変わる誤りの数）も比べる。評定は、素の Claude の文章も武将側と同じ手順で一次出典と照らす（H3）。
5. 限界（比喩や書きぶりから見分けられる可能性）も書く。
6. 結果を `【評定】` の全文の「素の Claude との比較」に書く。武将側だけの着眼点のうち、人物の視点の問いから来たと説明できるものには、どの人物のどの問いかを添える。
