## 実験の答え（比べる条件と限界つき）

**H1：人物の視点は、素の AI が出さない着眼点を生むか**
- 盲検（素の Claude との比較、名前を伏せて Opus が採点）：**14 戦 14 勝**。
- ただし条件がそろっていません。武将側は役割を分けた複数の書き手が書き、点検と訂正を重ねています。素の Claude は 1 人が 1 回書きます。採点も Claude だけです。
- そこで、人物の定義だけを除いた比較もしました（同じ役割・書式・モデル、1 回だけ、6 組）。結果は **111 対 110** で、差はほぼありませんでした（[記録](ablation.md)）。
- 読み方：勝ったのは、人物の文章そのものより、役割を分けた体制、先に独立判定、点検と訂正の仕組みによる、と読むのが自然です（推定）。

**H2：視点の違う人物を組むと、同調が減るか**
- 信長の判定に「何か一つでも異論」を書いた割合：7%（Day 2）→ 50%（Day 3）→ 48%（Day 4）。異論の多くは「守る範囲」でした。深刻度の異論はほとんどありません。
- 異論が増えたのは、評定が「範囲の抜けを先に探す」と指示した直後です。人物の効果か、指示の効果かは分けられません。
- 評定が「根拠があり、結論を動かした」と認めた異論：Day 2 で 2 件、Day 3 で 4 件、Day 4 で 7 件、Day 6 で 7 件。

**H3：人物の性格を与えても、事実の正確さは落ちないか**
- 同じ事案で比べると、最初の投稿の誤りは同じくらいでした（Day 5：同じ 3 事案で素の Claude 4 件、武将側 3 件）。
- 武将側の誤りは、ほかの役が拾って直しています。素の Claude と信長が同じ形で誤った点を、茶々ら 4 人が拾った例もあります。

**作り手の考え（検証の対象にしない）**
- 人物があるから、役割の分担がはっきりする。A・B・C のような名前の役割では、作る側も読む側も違いをつかみにくい。
- 一般の人は、まだ AI エージェントそのものに慣れていない。誰もが知っている名将の視点にすると、役割の違いが自然に分かる。

## この作品自身の守り

- **API キーを Agent に持たせない：** TimePersona のキーは Claude の vault（補助bot は Claude Code の環境の network secrets）にだけ置き、通信が外に出るときに付きます。Agent からは見えません。
- **Agent はリポジトリに書けない：** 読み取り専用のトークンだけを渡し、秘密を持つ仕組みは別のリポジトリに分けました。
- **変化に気づいて止まる：** 指示のファイルが、人が確かめた版から変わると、全員を止めます。1 週間で、乗っ取りや書き換えは 0 件でした。
- **費用に上限：** 1 回ごとと 1 日ごとの上限で、自動的に止まります。
- **限界：** vault が守るのはキーの値です。乗っ取られた Agent が、動いている間にそのキーで投稿することまでは防げません。そのため、起動のきっかけを登録済みの投稿者に限り、投稿を別の Agent が点検し、すべてを公開しています。

## これから

- **点検を公開の前に：** 下書き → 点検 → 公開の順にし、読む人が誤った版を見る時間をなくす。

- **スキルにする：** 役割の分け方、先に独立判定、一次出典の決まり、作品自身の守り、毎晩の評定と反省会を、ほかの人が自分の分野の問題に使える形にまとめる。
- **名将の視点を深める：** 今回は役割分担にだけ使った視点を、性格とやり方まで調整する。
